Set up the basemap

FogMap draws your fog and trails over a map of the world. That map is a Protomaps PMTiles archive, which is far too large to ship in a container, so it is downloaded once into the data directory and served from there.

The planet archive is around 128 GB. The download resumes if it is interrupted, and FogMap is fully usable while it runs — only the map underneath your trails is missing. Progress and a re-download button live under Settings, Basemap.
