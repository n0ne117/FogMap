Interface theme

Panels and controls. Independent of the map.

Map theme

Basemap, fog colour and trail colours. Both themes were rendered at import, so switching is instant.

Fog

How much of the map shows through ground you have not visited. At 100% the world behind is completely hidden. Applied in the browser, so it changes as you drag and nothing is re-rendered.

Set per map theme — this is the dark one. Unlike thickness, the colour is baked into the tiles, so applying it re-renders them. That takes a few seconds.

Tracks

Detailed draws one legible line per track, which is right until a hundred of them share a street and the whole area turns white. Faint draws hairlines that add up instead, so how often you went somewhere becomes the brightness. Auto picks whichever suits what is on screen. The trail colouring underneath is unaffected either way.

Borders

Drawn above the fog, so they stay readable over ground you have never been. The basemap has its own borders underneath, which the fog hides.

Brush

A range writes the stroke to every year it covers. Leave it blank and the stroke goes to prehistory, where undated memories live.

Drawing on the map

Use the pencil at the top right of the map to open the drawing toolbar. Drawing needs zoom 14 or closer: below that one screen pixel is wider than the brush, so the geometry would be meaningless.

Labels

What a pin looks like on the map. A pin with no label is drawn in the default colour; deleting a label leaves its pins in place and only takes the colour away.

Welcome to FogMap

FogMap draws your fog and trails over a map of the world. That map is a Protomaps PMTiles archive, far too large to ship in a container, so it is downloaded once into the data directory and served from there.

Checking.

The planet archive is around 128 GB. It resumes if interrupted, and FogMap is usable while it runs. Progress and a re-download button live under Settings, Basemap.

Your API token

Keep this somewhere safe. Every browser you want to edit from needs it — drawing, places, imports and the data source switches all ask for it. Reading the map never does.
